## ❓ FAQ

### Do I need to run it as Administrator?
No. This repository is an informational reference and does not include an executable or overlay.

### Does this repository include an evade executable?
No. It explains evade-script terminology, skillshot prediction concepts, and related game mechanics.

### Does it work on Windows 11?
Yes. The reference can be viewed on Windows 11 using a standard web browser.

### What does a League of Legends evade script do?
Evade scripts are designed to identify incoming skillshots and automate champion movement to avoid them. Riot specifically identifies automated skillshot dodging as an example of prohibited scripting.

### Can evade scripts be used with Vanguard?
Riot identifies gameplay automation and scripting as prohibited third-party behavior. Vanguard is Riot's anti-cheat system, and unauthorized tools can lead to account penalties, including permanent suspension in serious or repeated cases.
